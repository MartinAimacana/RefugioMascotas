# RefugioMascotas

## Descripción del proyecto

RefugioMascotas es un sistema de gestión de adopciones para un refugio de perros. Su objetivo es mejorar el registro de animales, la evaluación de posibles adoptantes y la asignación de mascotas mediante estructuras de datos y algoritmos en Java.

Este proyecto corresponde al **Progreso 1 de Programación III** de la Universidad de Las Américas (UDLA).

## Objetivo general

Diseñar un sistema informático que facilite la gestión de adopciones responsables de perros mediante la evaluación de compatibilidad, priorización de candidatos y seguimiento posterior a la adopción.

## Módulos del sistema

**Módulo 1: Usuarios y seguridad**
- Registro de usuarios.
- Inicio de sesión.
- Asignación de roles.
- Control de permisos.

**Módulo 2: Gestión de perros**
- Registro de mascotas.
- Fichas clínicas y conductuales.
- Búsqueda y filtrado.
- Priorización de atención.

**Módulo 3: Postulantes y solicitudes**
- Registro de postulantes.
- Gestión de solicitudes.
- Validación de información.
- Búsqueda de candidatos.

**Módulo 4: Evaluación y asignación**
- Cálculo de compatibilidad.
- Clasificación de postulantes.
- Ordenamiento por puntaje.
- Asignación de mascotas.

**Módulo 5: Seguimiento post-adopción**
- Programación de controles.
- Registro de seguimientos.
- Detección de controles pendientes.
- Generación de alertas.

**Módulo 6: Reportes y estadísticas**
- Consulta de adopciones.
- Estadísticas generales.
- Análisis de solicitudes.
- Generación de reportes.

## Tecnologías previstas

- Lenguaje: Java 17
- Entorno de desarrollo: IntelliJ IDEA
- Interfaz gráfica: Java Swing
- Estructuras de datos: ArrayList, HashMap, PriorityQueue y TreeMap
- Modelado: UML
- Control de versiones: Git y GitHub

## Algoritmos principales

El sistema contempla algoritmos de búsqueda, filtrado, ordenamiento y priorización de candidatos, además del cálculo de compatibilidad entre mascotas y adoptantes.

## Estado del proyecto

**Progreso 1: Análisis y diseño de la solución.**

Esta entrega contiene la formulación del problema, los módulos funcionales, el diseño UML, la comparación de alternativas y el plan preliminar de implementación.

La implementación completa en Java está prevista para el Progreso 2.
